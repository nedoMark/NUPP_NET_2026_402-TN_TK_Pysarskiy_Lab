# Лабораторна робота №2

Рішення продовжує першу лабораторну: асинхронний узагальнений CRUD, потокобезпечний доступ до колекції, пагінація, IEnumerable та асинхронне збереження JSON. Сторінки нумеруються з 1. Відсутній об'єкт при читанні викликає KeyNotFoundException; дубльоване створення, оновлення або видалення відсутнього ID повертає false. Помилки файлу передаються виклику як винятки.

Сервіс захищає структуру колекції через lock, а паралельні збереження одного екземпляра серіалізує через SemaphoreSlim. Передані об'єкти залишаються змінними посиланнями: не змінюйте їх властивості паралельно з операціями сервісу. Окремі екземпляри сервісу не координують запис в один файл.

Запуск із цієї папки:

    dotnet run --project Game.Console

Результат записується у characters.json; файл Результат.pdf містить вивід одного фактичного запуску. Випадкові значення відрізнятимуться під час наступних запусків.
