# Лабораторна робота №3

SQLite, Entity Framework Core 10, міграція InitialCreate, Fluent API, TPT, зв'язки 1:1, 1:N і M:N. Репозиторій використовує Guid для сумісності з попередніми лабораторними. Кожна операція CRUD одразу зберігається, тому SaveAsync підтверджує вже виконане збереження. Для кожної операції використовується окремий DbContext.

Запуск з кореня: `dotnet run --project Game.Console`. Програма використовує game.db у поточній папці та застосовує міграції.

Lab3_report_screenshots.pdf містить результат запуску, ERD та скриншоти структури бази і таблиці Characters. Додаткове завдання NoSQL не виконано.
