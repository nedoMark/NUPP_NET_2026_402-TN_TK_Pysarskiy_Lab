# Лабораторна робота №4

ASP.NET Core Web API для персонажів та зброї. Контролери використовують окремі моделі запитів/відповідей, DI, асинхронний CRUD-сервіс та EF Core репозиторій з лабораторної №3.

Запуск з кореня репозиторію: `dotnet run --project Game.REST`. База `game.db` з лабораторної №3 використовується за замовчуванням; її шлях можна перевизначити конфігурацією `DatabasePath`. Міграції застосовуються під час запуску. Адреса відображається у консолі.

Маршрути: `GET /api/characters`, `GET /api/characters/{id}`, `POST /api/characters`, `PUT /api/characters/{id}`, `DELETE /api/characters/{id}`; аналогічні маршрути для `/api/weapons`. Списки підтримують `page` (від 1) та `amount` (1–100).

Тіло запиту персонажа: `{ "name": "Hero", "health": 100 }`; зброї: `{ "name": "Sword", "damage": 40 }`. Результати перевірки на окремій тестовій базі містяться в Lab4_report.pdf. Додатковий проєкт MVC/Blazor не виконано.
